# 校园公众号写作风格指南（团队知识库 V1.0）

## 一、选题原则
面向大学生读者，选题必须贴近校园生活场景：学习、考试、求职、宿舍、社团、消费、心理健康。避免空洞说教，优先选择"痛点明确、有争议点、可给具体方法"的主题。标题要求口语化、有冲突感，禁用标题党式震惊体。

## 二、结构规范
文章标准结构为四段式：
1. 开头（150-300字）：用一个具体的大学生活场景切入，让读者产生"这就是我"的代入感；
2. 主体（3个分论点）：每个分论点必须包含"观点句 + 案例/数据 + 可执行建议"三要素，用小标题分节；
3. 结尾（100-200字）：总结核心观点，给一句可转发的金句；
4. 互动引导：结尾附一个开放式问题邀请评论区讨论。

## 三、语言风格
使用第二人称"你"与读者对话，语气平等不居高临下。句子长短交替，段落不超过4行。允许适度网络化表达（如"卷""摆烂""破防"），但每千字不超过5处，避免油腻。禁止使用"在当今社会""随着时代的发展""综上所述"等八股句式。

## 四、数据与事实规范
凡涉及统计数据、政策信息、考试时间等事实性内容，必须注明来源或通过检索核实，禁止编造。引用数据优先使用教育部、学校官方发布的公开信息。数据表述使用具体数字而非模糊形容（"65%的同学"优于"大多数同学"）。

## 五、配图规范
每篇文章配图3张：封面图（主题意象）、文中配图2张（分论点可视化）。配图风格统一为扁平插画风，色调明亮（主色：#6C5CE7 紫 + #00B894 青绿），避免实拍照片。封面图需要包含标题关键词的视觉隐喻。

## 六、审核标准
发布前必须通过以下检查：标题含核心卖点；字数1500-2500字；分论点均含案例或数据；无事实性错误；金句可独立转发；排版有呼吸感（每3-4段一次视觉停顿）。
